# Codexのレビュー実行条件

このファイルはCodex用の実行指示であり、共通レビュー方針や権限設定ファイルではない。

- ユーザー指定のモデル・推論量を使う。未指定なら実行セッションの設定を継承する。指定が利用できない場合は勝手に別の値へ置き換えず未完了とする。実効値を確認できなければ不明と報告する。
- 実行側で読取専用sandboxを設定し、承認は`on-request`など要求を表示できる設定にする。書込を許可する承認は行わず、変更可能な外部ツールも無効化する。これらの条件を確認できなければ開始せず未完了と報告する。
- 子agentにも同じモデル・推論量と読取専用条件を適用する。親側で設定し、子agentの設定ファイルやskill本文だけで権限を変更できるとは扱わない。
- skillを読むだけでは子agentは起動しない。親が独立した子agentを3人起動し、それぞれが指定された観点のskillを読んで1回実行し、親は全結果を待つ。会話履歴に依存しない入力を渡す。
- 委譲できない観点は未完了とする。親による代行を独立レビューと数えない。
- 起動時のモデル・推論量・権限条件と、実際に確認できた値を区別して報告する。

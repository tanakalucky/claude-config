# Codexのレビュー実行条件

このファイルはCodex用の実行指示であり、共通レビュー方針や権限設定ファイルではない。

- ユーザー指定のモデル・推論量を使う。未指定なら実行セッションの設定を継承する。指定が利用できない場合は勝手に別の値へ置き換えず未完了とする。実効値を確認できなければ不明と報告する。
- 実行側で読取専用sandboxを設定し、変更可能な外部ツールも無効化する。昇格は不可(`never`)または本人承認(`on-request`)とし、書込を許可する承認は行わない。`read-only + never`はsandbox外への昇格要求を拒否したまま実行する条件であり、全書込の自動承認ではない。これらの条件を確認できなければ開始せず未完了と報告する。
- 子agentにも同じモデル・推論量と読取専用条件を適用する。親側で設定し、子agentの設定ファイルやskill本文だけで権限を変更できるとは扱わない。
- 共通方針のGit読取限定はCodexのshellにも適用する。専用の読取ツールがなければ、ファイル名は`git ls-files`で確認し、機密・ignoredを除いた明示パスの現在の本文は`git diff --no-index -- /dev/null <path>`で取得する(差分ありの終了コード1は正常)。`cat`や`rg`を追加許可せず、`git show HEAD:<path>`を未commitの現在の本文の代わりに使わない。
- skillを読むだけでは子agentは起動しない。親が独立した子agentを3人起動し、それぞれが指定された観点のskillを読んで1回実行し、親は全結果を待つ。会話履歴に依存しない入力を渡す。
- 委譲できない観点は未完了とする。親による代行を独立レビューと数えない。
- 起動時のモデル・推論量・権限条件と、実際に確認できた値を区別して報告する。
